🏛️ Dianisma.gr — Το Νέο Ψηφιακό Δημοσιογραφικό & Αναλυτικό Portal
Το Dianisma.gr είναι ένας σύγχρονος ειδησεογραφικός και αναλυτικός ιστότοπος με επίκεντρο την Πολιτική, την Οικονομία, την Κοινωνία και τις Απόψεις. Στόχος του project είναι να προσφέρει ταχύτατη ενημέρωση, καθαρή αναγνωστική εμπειρία χωρίς περισπασμούς και πλήρη βελτιστοποίηση για τις μηχανές αναζήτησης (SEO).

🎯 Τι περιλαμβάνει το Project
📰 Σύγχρονη Αρχική Σελίδα:

Κεντρικό πρωτοσέλιδο (Hero Grid) για τα σημαντικότερα θέματα της ημέρας.

Δυναμικό πλέγμα άρθρων 3x3 με κουμπί «Φόρτωση Περισσοτέρων» (AJAX Load More) για να διαβάζει ο χρήστης συνεχόμενα χωρίς ανανεώσεις.

Αυτόνομες θεματικές ενότητες: Πολιτική, Οικονομία, Αναλύσεις, Απόψεις, Κοινωνία.

🔍 Τεχνικό SEO & Κοινοποίηση στα Social Media:

Πλήρης υποστήριξη Schema.org (JSON-LD) ώστε η Google να αναγνωρίζει αμέσως τα άρθρα ως NewsArticle.

Αυτόματη παραγωγή sitemap.xml και robots.txt για άμεση ευρετηρίαση.

Βελτιστοποιημένα Open Graph & Twitter Cards για εντυπωσιακή εμφάνιση των links όταν κοινοποιούνται σε Facebook, X (Twitter), κ.ά.

⚖️ Νομική Συμμόρφωση & GDPR:

Ενσωματωμένο banner συγκατάθεσης cookies (Cookie Consent Banner).

Έτοιμες σελίδες για Όρους Χρήσης, Πολιτική Απορρήτου, Cookies, Πνευματικά Δικαιώματα & Επικοινωνία.

⚙️ Πλήρες Πάνελ Διαχείρισης (Custom Admin):

Εύκολη δημοσίευση, επεξεργασία και κατηγοριοποίηση άρθρων.

Διαχείριση συγγραφέων, συντακτών και χρηστών.

Σύστημα υποβολής αιτήσεων για νέους εξωτερικούς αρθρογράφους.

🛠️ Τεχνολογίες (Tech Stack)
Πίσω μέρος (Backend): Python 3.13 & Django Framework

Εμφάνιση (Frontend): HTML5, Jinja2 Templates, Custom CSS (Editorial Design) & JavaScript

Βάση Δεδομένων: SQLite (για ανάπτυξη) / Έτοιμο για PostgreSQL (σε παραγωγή)

Έκδοση & Διαχείριση Κώδικα: Git & GitHub

🚀 Οδηγός Εγκατάστασης για Προγραμματιστές
Αν θέλετε να τρέξετε το project τοπικά στον υπολογιστή σας:

Κάντε Clone το Repository:
git clone https://github.com/Giannis-Spyropoulos/Dianisma-Site.git
cd Dianisma-Site

Δημιουργήστε και ενεργοποιήστε Εικονικό Περιβάλλον (Virtual Environment):
python -m venv venv
# Σε Windows:
venv\Scripts\activate
# Σε Linux / macOS:
source venv/bin/activate

Εγκαταστήστε τις απαιτούμενες βιβλιοθήκες:
pip install -r requirements.txt

Εκτελέστε τα Migrations της βάσης:
python manage.py migrate

Ξεκινήστε τον τοπικό server:
python manage.py runserver
