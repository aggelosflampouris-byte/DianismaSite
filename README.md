## 📰 Σχετικά με το Project

Το **Dianisma.gr** είναι ένα σύγχρονο ψηφιακό **ειδησεογραφικό και αναλυτικό portal**, σχεδιασμένο με στόχο να προσφέρει μια γρήγορη, καθαρή και εύχρηστη εμπειρία ενημέρωσης.

Η πλατφόρμα επικεντρώνεται σε:

* 🏛️ **Πολιτική**
* 💶 **Οικονομία**
* 🔎 **Αναλύσεις**
* 💬 **Απόψεις**
* 👥 **Κοινωνία**

Το project συνδυάζει **μοντέρνο editorial design**, δυναμική διαχείριση περιεχομένου, βελτιστοποίηση για **μηχανές αναζήτησης (SEO)** και υποδομή έτοιμη για παραγωγικό περιβάλλον.

# 🎯 Κύρια Χαρακτηριστικά

## 📰 Σύγχρονη Αρχική Σελίδα

Η αρχική σελίδα έχει σχεδιαστεί ώστε να παρουσιάζει άμεσα τα σημαντικότερα θέματα και να επιτρέπει στον χρήστη να περιηγείται γρήγορα στο περιεχόμενο.

### ✦ Κεντρικό Πρωτοσέλιδο

**Hero Grid** για την ανάδειξη των σημαντικότερων και πιο πρόσφατων άρθρων.

### ✦ Δυναμικό Article Grid

Πλέγμα άρθρων **3×3**, με δυνατότητα δυναμικής φόρτωσης επιπλέον περιεχομένου μέσω:

```text
AJAX → Load More
```

Έτσι ο χρήστης μπορεί να συνεχίσει την περιήγηση **χωρίς ανανέωση της σελίδας**.

### ✦ Θεματικές Ενότητες

Το περιεχόμενο οργανώνεται σε ξεχωριστές κατηγορίες:

| Κατηγορία        | Περιεχόμενο                           |
| ---------------- | ------------------------------------- |
| 🏛️ **Πολιτική** | Πολιτικές ειδήσεις και επικαιρότητα   |
| 💶 **Οικονομία** | Οικονομία, αγορές και επιχειρήσεις    |
| 🔎 **Αναλύσεις** | Εκτενέστερη ανάλυση της επικαιρότητας |
| 💬 **Απόψεις**   | Άρθρα γνώμης και σχολιασμός           |
| 👥 **Κοινωνία**  | Κοινωνικά θέματα και καθημερινότητα   |

# 🔍 SEO & Social Media

Το Dianisma.gr έχει σχεδιαστεί με έμφαση στη **μηχανή αναζήτησης και την οργανική επισκεψιμότητα**.

### 🧠 Structured Data

Υποστήριξη **Schema.org / JSON-LD**, ώστε το περιεχόμενο των άρθρων να μπορεί να αναγνωρίζεται σωστά από τις μηχανές αναζήτησης ως:

```text
NewsArticle
```

### 🗺️ Sitemap & Robots

Αυτόματη δημιουργία:

* `sitemap.xml`
* `robots.txt`

για καλύτερη δυνατότητα **crawling και indexing** από τις μηχανές αναζήτησης.

### 📱 Social Sharing

Βελτιστοποιημένα metadata για κοινοποίηση περιεχομένου σε social media:

* **Open Graph**
* **Twitter Cards**
* Social preview images
* Article metadata

Στόχος είναι κάθε άρθρο να εμφανίζεται σωστά και ελκυστικά όταν κοινοποιείται σε πλατφόρμες όπως **Facebook, X (Twitter)** και άλλες υπηρεσίες.

# 🚀 Εγκατάσταση

## 1️⃣ Clone το Repository

```bash
git clone https://github.com/Giannis-Spyropoulos/Dianisma-Site.git
cd Dianisma-Site
```

## 2️⃣ Δημιουργία Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Εγκατάσταση Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Εκτέλεση Database Migrations

```bash
python manage.py migrate
```

---

## 5️⃣ Εκκίνηση Development Server

```bash
python manage.py runserver
```

Στη συνέχεια, ανοίξτε στον browser:

```text
http://127.0.0.1:8000/
```
